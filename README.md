# 📚 Library Visit Monitoring System

A web-based system to track and manage student and staff visits to the college library. The project is built using **PHP, MySQL, JavaScript, and Bootstrap** to provide an efficient and user-friendly platform for librarians and administrators.

---

## 🚀 Features
- **User Authentication** for Admins and Librarians
- **Student & Staff Management**
  - Import data via Excel templates
  - Add, update, and remove users
- **Library Visit Logging**
  - Record student and staff entry/exit
  - Track active and historical visits
- **Data Management**
  - Branch and faculty management
  - Automatic removal of old history data
- **Reports & Analytics**
  - Export visit records
  - Generate charts with Highcharts integration
- **Responsive Design** with Bootstrap & DataTables
